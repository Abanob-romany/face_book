# Facebook UI Clone - Flutter App

This project is a **Facebook UI clone** developed in Flutter, featuring a **native splash screen**, **login page with mock user logic**, and a sleek **home screen** with stories and posts — all inspired by Facebook's core interface and user flow.

Whether you're a developer looking for inspiration or just curious how Facebook's design translates into Flutter — you're in the right place!

---

## ✨ Features

- **Splash Screen**
  - Simple and clean native-style splash with the Meta branding

- **Login Page**
  - Styled exactly like Facebook’s login screen
  - Accepts fake/static user credentials
- **Mock User System**
  - Predefined list of fake users with emails/passwords
  - Can easily be extended to real user handling

- **Home Screen**
  - Top app bar with Facebook logo, icons, and user profile
  - Scrollable **Stories** section
  - **Posts Feed** showing static sample content
  - Icons for like, comment, and share (non-functional but animated)

---

## 🛠 Tech Stack

- **Flutter**
- **Dart**
- Native splash with `flutter_native_splash`
- Figma-inspired UI design
